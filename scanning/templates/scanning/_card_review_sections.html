Text in no box (…)

A block of print the reader saw that no box covers, a footnote line outside the footnote box included. The opinion text leaves out what the boxes miss: add a column box over the block (resize it first if it is short), grow the footnote box beside the block over it (one box, no seam; one is added when none is near), or pull the page's own column box over it (click the box's label on the crop and drag its edge); box it as an editor's note when it is the publisher's text (a Words and Phrases line), which the redaction then blacks out; or say it is not text (the print of the leaf behind, a stray mark).

Images (…)

An image box the model drew and nobody has judged, and a picture or a table the readers (dots.mocr, Mistral, Surya) saw that no image box covers. The opinion PDF pastes the original scan of an image box over the page, so a box over text pastes a photograph of the text, and a picture with no box is read as words. Keep a box, pull it in, or take it out; where the readers draw the picture differently, Refine image box pulls the box to theirs (hover the button to see where); add an image box at the readers' box, or say it is not an image.
