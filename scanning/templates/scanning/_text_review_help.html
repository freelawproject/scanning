Select and lock

  • Point to a block of the text or to a box of the page. The other column goes to the same block and marks it.
  • Double click a block or a box to lock it. The readings of each engine open under the block{% if can_edit %}, and so does its menu{% endif %}.
  • Click outside the locked block to release it.
{% if can_edit %}

The menu of a locked block

  • Edit text writes the text of a block the engines did not read alike.
  • Move up and Move down change the order of the blocks.
  • Put in the footnotes moves the block and the body blocks below it in the same column. Put in the body text moves one block back.
  • Undo gives back what the engines and the detections read. Nothing is deleted.
{% endif %}

Colours

  • Red: the engines did not agree, and the approval waits for a person.
  • Yellow: a majority of the engines read the block alike.
  • No box: every engine read the block alike. Show the blocks all engines agree on draws these boxes.
  • Footnote zone: the footnote detections of the page. A dotted band shows the footnotes set by hand.
  • Blockquote zone: the blockquote detections of the page.
  • A double border is a footnote block. A green edge on a text block shows text a person wrote.
